把连续真机记录投影成
因果一致的运行时轮次。

真机示教记录的是连续传感器流和动作流，不是 Code as Runtime 需要学习的轮次级因果决策。直接切片可能泄漏未来帧、忽略推理延迟，或改写机器人已经执行的动作。本文提出在校准后的时间线上重放整个任务回合，再将其投影为带有明确 Action Queue 状态、字段来源链和重放检查的上下文 → 决策样本。投影数据集和训练后策略均未完成评测。

DROID[10] 与 Open X-Embodiment[11]提供真机轨迹和标准化格式，但都没有验证本文的投影器。

01 · SFT 投影目标

把原始记录和
投影轮次分开保存。

原始记录是不应改写的证据。构造 SFT 样本时，必须明确选择 Agent 唤醒时刻、推理延迟、可见观测、Action Queue 状态和目标决策，并记录这些选择；未来信息不得进入策略输入。

投影不是改写事实。

同一个原始任务回合可以产生多种决策时刻或代码表达，但每个合成字段都要保留来源、方法和置信度。来自未来帧、人工修正或仿真真值的信息只能存在于教师附属数据中，不能伪装成策略输入。

02 · 规范事件账本

把所有数据流
对齐到同一任务时钟。

视频帧、控制命令、机器人实际运动与接触反馈并不同时到达。Open X-Embodiment 展示了跨机器人形态统一数据格式的重要性[11]。这里还要先保留各数据流的原始时间戳，再建立经过校准的任务时钟；否则，一个看似合理的轮次可能已经使用尚未到达的图像。

03 · 伪时间重放

推理期间，
机器人并没有停下来。

同步切片会产生一种不存在的世界：Agent 看完一段动作的最终结果，再决定这段动作该怎么写。RTC 明确刻画了“模型推理时旧 Action Chunk 仍在执行”以及冻结已执行前缀的异步约束[6]；VLA-Corrector 则研究了检测偏离后缩短执行时域的方法[12]。本篇据此沿示教轨迹做伪时间回放。

01选择唤醒点

混合使用固定步长、阶段事件和异常事件；不要只在“正确答案显然”时唤醒。

02采样推理延迟

从目标模型的延迟分布采样 d，而不是假设决策瞬时产生。

03冻结执行前缀

推理期间已发送或已执行的动作不可撤回，只有 Action Queue 中尚未执行的尾部可以替换。

04随机化截断节奏

在偏离前、偏离点与偏离后混合截断，避免策略只学会单一时间模式。

04 · 从运动到运行时决策

代码重放失败时，
保留直接 Action Chunk。

Demo2Code 已探索从示教摘要到可执行机器人代码的两阶段合成[9]。这里先按接触、曲率、速度和任务阶段切分稠密动作，再尝试用受限动作原语重建。低曲率、非接触段通常适合压缩成代码；接触丰富或拟合失败的段则保留为 ACT 类 Action Chunk[4]。只有通过重放验证的片段才改写为代码；其余片段保留真实 Action Chunk。

05 · 建议的最小轨迹结构

一条任务轨迹，
产生多轮 SFT 样本。

每轮都以 available_until 之前可用的上下文为输入，并记录决策何时生效。唤醒、提交和更新后的队列快照保存推理期间已经变得不可撤回的前缀；工具结果和执行事件进入下一轮上下文。这是建议的最小结构，不是稳定的数据格式。

因果边界available_until

所有策略输入必须能证明在该时刻之前已经到达。

队列一致性queue_at_wake / commit / after_update

保留不可撤回前缀，并使每次更新都可离线重放。

可观察推理decision / program / events

监督外显决策与执行结果，而不是假定存在唯一隐藏 CoT。

07 · 过滤与验收

数据是否能训练，
先看它能否通过因果审计。

成功的任务回合不自动等于好数据。真正危险的是“成功但理由错误”的轨迹：使用未来帧、泄漏真值、把人类接管归给 Agent，或用无法重放的代码解释动作。过滤器必须在训练前找出这些捷径。

时间泄漏是否有任何 context ref 晚于 available_until？
重放等价性code 展开后与采集轨迹的误差是否低于分段阈值？
队列有效性是否修改了已经执行，或已经下发且不可撤回的前缀？
特权信息泄漏真值、人工修正与事后帧是否进入了策略输入？
干预归因人类接管前后是否切段，并标清控制权归属？
失败样本价值失败是否包含可定位端点与后续恢复，而非只有最终失败标签？
媒体完整性所有外部图像、sensor window 与 chunk 引用是否存在且可解码？
投影置信度低置信合成字段是否被降权、送审或排除出 SFT？

这条拟议管线应生成多轮 SFT 样本：每个输入只包含当时已经可见的上下文，每个目标只包含下一次可执行的 Agent 决策。RL 可以复用同一轨迹结构。对 SFT 的验收应逐轮重放，并确认上下文、队列状态和目标与原始任务记录一致。因果可见性和重放保真度仍是待评估目标。

在把轨迹用于训练前，应报告因果审计通过率、各类片段的重放误差，以及投影字段的置信度分布。本文尚未报告投影数据集或训练后策略的实验结果。查看全部参考文献 →
