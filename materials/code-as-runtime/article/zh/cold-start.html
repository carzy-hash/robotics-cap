在策略尚不能稳定执行在线采样时，仿真真值可以为强化学习前的冷启动提供可行解和检查标签。但如果轨迹声称视觉系统推导出了它从未观察到的精确量，就会制造不可部署的因果捷径。目标是按部署输入形态完成初始化，而不是让特权求解器长期替代在线探索。

教师残差

Magic Offset 只用于冷启动监督

delta_magic = g_star - g_vis
label(refine_grasp, delta_magic)
record(privileged=true,
       residual=delta_magic,
       projection_error=...)

该偏移用于训练可部署的残差辅助函数，并在课程中逐步归零；它不能伪装成视觉观测。

策略输入只包含仿真和真机都可获得的观测、状态与 API。
教师侧附属数据单独保存真值、Magic Offset、特权动作、失败原因和标签置信度。
验收条件撤掉附属数据后重新执行；只有仅依赖观测的策略仍通过验证器，才能进入下一阶段。

这种投影方法可能如何用于其他任务

放置稳定放置

真值支撑面和稳定姿态产生特权目标；视觉场景重建产生候选，残差教师监督最终姿态细化。

关节机构门与抽屉

真值关节轴和接触点产生可行轨迹；策略从视觉与力反馈估计关节状态，并学习何时更新力反馈处理器。

遮挡主动观察

真值可见性图选择最佳相机位；投影轨迹则根据不确定度调用视角切换和多帧融合。

恢复失败恢复

仿真直接给出滑动、碰撞或抓取失败的原因；策略只看到可观测症状，并学习重新观察、回撤或停止。

只有关闭教师附属数据后，新执行的轨迹仍能通过普通训练所用的独立验证器，冷启动才能通过验收。以上模式均为设计提案；本附录未报告训练后策略或迁移结果。
